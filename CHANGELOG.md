# История версий

Версия установщика: `bash install.sh --version`. Правило: каждое обновление = новая версия + запись здесь + строка в README.

## 1.3.9 — 2026-10-14
- Проверка (`goji-node check`): в строке «Путь XHTTP» теперь показывается сам путь, а не только пометка «свой для этого сервера». «Свой» = случайный путь, сгенерированный для этого сервера; общий публичный `/api/v2/telemetry/` помечается предупреждением.

## 1.3.8 — 2026-10-14
- Все 10 статических сайтов-заглушек переписаны с нуля как правдоподобные вымышленные сайты с реальными фото (freelancer, agency, creative, grayscale, resume, blog, new-age, saas, docs, analytics).
- Убраны lorem ipsum, шаблонные названия, чужие логотипы, внешние CDN-скрипты и шрифты; формы работают только в браузере.
- Фото из MIT-репозиториев GitHub, лицензии — `xhttp-tls/templates/THIRD-PARTY-NOTICES.md`.
- После обновления на сервере: `bash install.sh --resume --template <имя>`.
