Monitoring as code

Create and update checks from your pipeline. The API is versioned, documented and rate-limited generously.

Heartbeat URLs are signed — no API key needed in your cron scripts.

# create an HTTP check
curl -X POST https://api.stackpulse.example/v1/checks \
  -H "Authorization: Bearer $SP_TOKEN" \
  -d '{"name":"api health","url":"https://api.example.com/health","interval":30,"regions":["eu","us","ap"]}'

# ping a heartbeat when your job finishes
curl -fsS https://hb.stackpulse.example/8f3a1c
